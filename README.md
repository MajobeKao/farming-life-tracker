# 🌾 Farming & Life Tracker

A comprehensive offline-first web application for tracking farming activities, daily life, finances, goals, and more.

## Features
- 🌾 Farming: Crops, fields, costs, harvest, profit
- 📅 Daily Life: Sleep, work, prayer, exercise, study, habits
- 💰 Money: Salary, income, expenses, savings, balance
- 🎯 Goals: Daily, monthly, yearly tracking
- 🔔 Reminders: Tasks and events
- 📊 Reports: Daily, weekly, monthly summaries
- 📸 Photos & Notes: Evidence and records

## How to Use
1. Open `index.html` in any browser
2. All data is stored locally in your browser
3. No internet connection required after first load

## Development
- Open with VS Code
- Edit `index.html` for all functionality
- Data persists in browser's localStorage
